# 허브집사 (6일차 과제)

- 작업을 시작하기 전에 `PROGRESS.md`를 읽고 현재 상태와 결정한 것을 파악한다.
- 의미 있는 작업을 마치면 `PROGRESS.md`의 "지금 상태"와 "다음 할 일"을 갱신한다.
- 사용자는 한국어로 소통한다. 안내, 다음 단계, 버튼까지 모두 한국어로 쓴다. 과제는 핵심 목표만 유지한다.
- **앱허브 코드(`~/Documents/kg-tools/kigleAppBoard`)는 고치지 않는다.** 봇은 과제 제출용이라 나중에 떼어낼 수 있어야 한다. 봇은 앱허브 배포용 wrangler 로그인으로 D1을 직접 읽는다(`scripts/apphub.js`의 고정 SELECT만).
- 봇은 읽기만 한다. 디스코드에서 쓰는 도구는 `mcp-apphub` 하나뿐이다(터미널·파일 도구를 주지 않는다).
- `.env`는 git에 올리지 않는다. 봇 토큰은 채팅에 붙여넣게 하지 말고, 사용자가 `.env`에 직접 넣게 한다.
- 커밋과 푸시는 사용자가 요청할 때만 한다.
- Hermes는 이 폴더 안에 있다: 코드 `hermes-agent/`, 데이터 `hermes-home/`(둘 다 git 제외). `hermes` 명령은 `npm run hermes -- ...`로 실행한다. 프로필 `hubjipsa`, 포트 8661.
